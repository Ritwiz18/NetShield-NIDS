FINAL ROOT CAUSE:

1. Interface Ordering / Default Selection:
   Previously, get_available_network_interfaces() listed system adapters in raw
   Scapy order where index 0 was 'Local Area Connection* 12 (WAN Miniport)'.
   WAN Miniports carry 0 user network traffic, so sniffing on the default interface
   yielded 0 packets.
   Fix: Interface discovery now scores and sorts adapters, placing the active physical
   interface with an assigned IPv4 address (e.g. Wi-Fi AX101 [192.168.1.18]) at Index 0.

2. Streamlit Static Render Model:
   When START MONITORING was clicked, Streamlit triggered an immediate rerun at t=0ms,
   reading snapshot metrics before packets could be captured (all 0), and then never
   refreshed automatically.
   Fix: Added an automatic 1-second dynamic refresh loop when engine state is RUNNING,
   and bound snapshot recent_detections and incidents_list to the Live Detections table.

3. Scapy Callback Verbosity:
   PacketCaptureWorker returned a boolean from prn, causing Scapy to print 'False'
   per packet. Fixed to return None.
