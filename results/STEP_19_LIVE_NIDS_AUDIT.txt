3. FEATURE DEFINITIONS & UNITS
--------------------------------------------------
- Duration / IAT Features: Microseconds (µs)
- Length Features: Bytes
- Rate Features: Per second (Bytes/s, Packets/s)
- TCP Flags: Integer occurrence counts across packets
- Window Sizes: Bytes (advertised TCP window)
- Segment Sizes: Bytes (TCP header data offset)
- Active / Idle Sub-flow Statistics: Microseconds (µs) with 5.0s idle threshold
