STEP 25 LIVE IMPORT FIX REPORT
==================================================

Original Error:
No module named 'live'

Root Cause:
Streamlit adds the SCRIPT directory (D:\NetShield-NIDS\app\) to
sys.path when launching with:

    streamlit run app\app.py

It does NOT automatically add the project root
(D:\NetShield-NIDS\). The live/ package lives at the project
root, so Python could not find it from inside the app/ context.

Additionally, the previous except clause was:

    except ImportError:
        pass

...which silently swallowed the error and left all imported names
undefined (causing NameError at runtime). This was fixed in the
prior session to use explicit stubs, but the root path issue
remained.

==================================================
FIX APPLIED
==================================================

File: app/app.py (lines 33-36)

Added explicit project root injection before all live imports:

    _PROJECT_ROOT = os.path.dirname(
        os.path.dirname(os.path.abspath(__file__))
    )
    if _PROJECT_ROOT not in sys.path:
        sys.path.insert(0, _PROJECT_ROOT)

This uses __file__ (the absolute path of app.py) to compute
D:\NetShield-NIDS regardless of how or from where Streamlit
is launched.
