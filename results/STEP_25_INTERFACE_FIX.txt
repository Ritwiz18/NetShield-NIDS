==================================================

Original Error:
AttributeError: 'tuple' object has no attribute 'keys'
Location: app/app.py line 1418

Root Cause:
There were TWO definitions of get_available_network_interfaces():

1. IMPORTED from live.capture (line 50):
   Returns: dict   {display_name: iface_obj}

2. LOCAL DUPLICATE in app.py (line 550):
   Returns: tuple  (iface_dict, None)

The local definition on line 550 SHADOWED the imported
version. Python uses the last-defined name, so:

    iface_dict = get_available_network_interfaces()

assigned a TUPLE (dict, None) to iface_dict.

Then:

    options=list(iface_dict.keys())

crashed because a tuple has no .keys() method.

==================================================
FIX APPLIED
==================================================

Removed the local duplicate function (app.py lines 550-567).

The imported version from live/capture.py is now the sole
definition. It returns a plain dict, which is what the UI
code on line 1418 expects.

No other call sites existed. No tuple unpacking was used
anywhere for this function.
